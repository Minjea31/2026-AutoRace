# AutoRace Web Viewer

기본 웹뷰어 실행 방법은 [미션 웹뷰어 안내](MISSION_WEB.md)를 참고하세요. 아래는 `run_legacy.sh`로 실행하는 카메라·ROI·주차 뷰어 안내입니다.

## 흰색 ROI 웹 조절

같은 Wi-Fi에서 **http://192.168.50.83:8080/roi**를 엽니다.
기본 화면은 `/home/wego`에 마지막으로 기록한 카메라 bag입니다.
이전/다음 프레임, ±1초 버튼, 시간 슬라이더로 이미지를 고르고
ROI 내부 드래그로 이동, 모서리 드래그로 크기를 조절합니다.
빈 곳을 드래그하면 새 영역을 만듭니다. 숫자와 슬라이더로도 조절할 수 있습니다.
흰색 최소 비율과 HSV S 최대/V 최소도 미리보기에서 조절할 수 있습니다.

미리보기는 `autorace_crosswalk.white_roi`의 실제 검출 코드를 사용합니다.
raw bag 이미지는 무손실로 읽고, 원본 영상 기준 좌표와 흰색 비율을 계산합니다.
횡단보도와 서행/방지턱 중 미션을 선택하면 해당 소스 YAML 기본값을 불러옵니다.
HSV 초기값은 real lane.yaml을 읽습니다(실행 중 노드에서 조회한 값은 아닙니다).
`영상 + 파라미터 캡처`로 이미지·bag 시간·ROI·흰색 비율·HSV·파라미터를 PNG에 저장합니다.
값 복사 및 YAML 다운로드도 지원하며 **실제 미션 노드나 설정 파일은 변경하지 않습니다.**
캡처를 공유한 뒤 최종 적용할 수 있습니다. 새 bag은 `새로 불러오기`로 선택합니다.

실시간 카메라와 JPEG/PNG 업로드도 지원합니다.
ROI 편집 중에만 원본 `/camera/color/image_raw` 또는 compressed 카메라를 구독하며,
편집을 중단하면 요청 구독은 몇 초 후 해제합니다. bag 탐색에는 ROS 재생이 필요 없습니다.
서버는 차량 제어 메시지나 파라미터 변경 요청을 발행하지 않습니다.


## 주차 상단 뷰

83 차량에서는 `ROS_DOMAIN_ID=94 PORT=8080 FPS=5 ./run_legacy.sh`로 시작한 뒤
같은 Wi-Fi에서 `http://192.168.50.83:8080/parking`에 접속합니다.
주차 미션 활성화 시 RViz와 같은 토픽의 실시간 라이다, 기억 장애물, 탐색 구역,
계획 경로, 목표와 lookahead를 차량 기준 상단 뷰로 표시합니다.
2×3 주차칸은 `/parking/status`에 포함된 실제 매칭 결과를 사용하며
점유·빈 칸 후보·선택 목표·매칭 관측 수·RMSE·가설 수·맵 확정 여부를 보여줍니다.
지도 매칭을 새로 실행하거나 차량을 제어하는 기능은 없습니다.
아직 매칭되지 않았거나 위치 추정이 무효한 경우에는 과거 지도를 표시하지 않습니다.
미션 종료, 새 시도, 위치 초기화와 수신 중단 시 이전 오버레이를 비웁니다.
확대·축소·드래그·화면 맞춤·전체화면·레이어 표시와 전방 카메라를 지원합니다.
화면은 독립 프로세스로 임시 실행되며, 자동 부팅 등록은 하지 않습니다.
종료하려면 실행한 터미널에서 `Ctrl+C`를 누릅니다.

플랫폼이 ROS 영상을 수신해 HTTP로 제공합니다. 같은 네트워크의 PC에서 브라우저만으로 접속합니다.

```bash
cd ~/2026-AutoRace/web_viewer
./run_legacy.sh
```

접속 주소: `http://192.168.50.97:8080` (플랫폼 IP가 바뀌면 새 IP 사용).
기본 ROS_DOMAIN_ID는 96입니다. 센서와 같은 도메인을 사용하세요.

```bash
ROS_DOMAIN_ID=96 PORT=8080 FPS=10 ./run_legacy.sh
```

| 화면 | 수신 토픽 |
| --- | --- |
| 카메라 원본 | `/camera/color/image_raw/compressed` |
| YOLO bbox | `/yolo/debug/compressed` |
| 차선 마스크 | `/lane_fusion/deep_mask` |
| 차선 디버그 | `/lane_fusion/debug` |
| 서행·방지턱 바닥 ROI | `/slow/white_roi/debug/compressed` |

YOLO 화면은 bbox 아래에 클래스, 가로×세로, 면적(px²)을 작게 표시합니다.
해당 프레임에서 실제 검출 신호 발행 조건을 만족한 bbox는 클래스별 색상, 나머지는 회색입니다.
좌회전 토픽의 False도 정상 발행이므로 색상으로 표시합니다.

차선 노드가 꺼져 있으면 해당 화면은 대기 상태입니다. 웹 서버는 미션 노드를 시작하거나 차량 제어 명령을 발행하지 않습니다.
JPEG 카메라는 재인코딩 없이 전달하고, raw 마스크·디버그는 프레임당 한 번 JPEG로 변환합니다. 기본 전송 상한은 각 영상 10FPS이며, 여러 브라우저가 인코딩 결과를 공유합니다.
이미지 저장, 전체화면, 영상별 보기, 수신 상태 및 자동 재연결을 지원합니다.

ROS Humble의 시스템 Python(`/usr/bin/python3`), rclpy, sensor_msgs, NumPy, OpenCV를 사용합니다. pip 설치나 colcon 빌드는 필요하지 않습니다.
LAN용 HTTP 서버이며 별도 로그인은 없습니다. 자동 부팅 등록은 하지 않습니다.
