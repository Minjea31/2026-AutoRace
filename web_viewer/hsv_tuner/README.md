# Bag HSV 튜너

녹화된 카메라 bag을 재생하면서 H/S/V의 하한·상한 6개 값을 조절합니다.
원본 전체의 검출 영역과 이진 마스크를 나란히 표시하고, 공통 ROI에서
흰색 비율이 8% 이상이면 감지 문구를 표시합니다.

플랫폼 실행:

```bash
cd ~/2026-AutoRace/web_viewer/hsv_tuner
bash run.sh --port 8091
```

같은 네트워크의 브라우저에서 `http://192.168.0.106:8091`에 접속합니다.
기본 bag 경로는 저장소의 `bags/`이고, 카메라 프레임이 있는 bag만 목록에 나옵니다.
다른 경로는 `--bag-root /absolute/path`로 지정할 수 있습니다.

재생/일시정지, 속도, 반복, 프레임 이동, ±1초, 시간 슬라이더를 지원합니다.
Space는 재생/정지, 방향키는 프레임 이동입니다.
HSV 변경은 브라우저에 보관되며 JSON 파일로 다운로드할 수 있습니다.

초기 HSV와 ROI는 플랫폼의 실제 차선·횡단보도 설정 파일에서 읽습니다.
전체 화면에는 5×5 Gaussian blur 후 HSV 범위를 적용하고, ROI에는 미션 코드와
같이 **원본을 자른 뒤 blur**를 적용합니다. ROI의 마스크와 비율은 동일한 픽셀로
계산합니다. 기본 6개 값은 현재 미션 검출 코드의 결과와 같습니다.

기존 플랫폼의 미션은 S 상한/V 하한만 설정할 수 있습니다. 이 웹은 6개 범위를
탐색하기 위한 도구이며 플랫폼 설정을 변경하거나 ROS bag/주행 노드를 실행하지 않습니다.
bag의 카메라 프레임을 읽어 원래 시간 간격으로 표시하고, 느린 연결에서는 중간 화면을
건너뛰어 재생 속도를 유지합니다. 일시정지 후 프레임 이동으로 모든 프레임을 볼 수 있습니다.

ROS Humble 시스템 Python, OpenCV, NumPy, PyYAML 외에 추가 설치가 필요 없습니다.
