# Repository guidelines

- Use the repository owner's Git identity for both author and committer: `Minjea31 <kimminjea31@naver.com>`.
- Check recent commit messages before committing. Follow the existing short English style, such as `add ...`, `edit ...`, or `fix ...`.
- Keep commit messages focused on the actual changes. Do not add tool names, generated-by notices, attribution footers, or co-author trailers.
- Commit and push only the changes requested by the user. Preserve unrelated work.
