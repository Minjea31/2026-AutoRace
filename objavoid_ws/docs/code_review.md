# 복원한 버전

계속 회전하는 문제를 수정한 직후, RViz 분리/런치/간단 로그를 추가하기 전 버전이다.
단일 objavoid_node에서 센서 처리·회피 판단·제어·RViz를 실행한다.
tracking.py는 별도 ROS 노드가 아니라 목표 횡위치와 정렬 조향을 계산하는 내부 모듈이다.

고정 목표 조향과 절반 조향만 긴/짧은 패스로 검사한다. 이후 추가한 대체 조향 후보는
제외했다. 목표 후보가 막히면 STOP_TARGET_BLOCKED로 정지하는 당시 동작도 복원했다.
실행은 README의 ros2 run 명령을 사용한다.

알고리즘 설정은 43개이며 토픽·활성화·시뮬 시간까지 YAML은 49개다.
차량/센서 캘리브레이션, 안전 검사, 제어 튜닝과 통신 설정을 포함한다.
